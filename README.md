### `projects --featured`

<table>
<tr>
<td width="50%" valign="top">

**🔍 Hallucination Hunter**

Claim-level verification for LLM output. Splits a response into
individual claims, checks each one against retrieved evidence with an
NLI model, and scores the result — instead of trusting the model's own
confidence.

`DeBERTa` `XGBoost` `FastAPI` `NLI validation`

</td>
<td width="50%" valign="top">

**🌾 AgriMind**

Voice-first crop recommendation for growers who'd rather talk than
type. Whisper transcribes, a RandomForest model scores the field
conditions, and the whole pipeline runs on CPU — no GPU required in
the field.

`Whisper` `RandomForest` `CPU inference`

</td>
