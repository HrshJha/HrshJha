## ◈ RELIABILITY MANIFEST

```cpp
namespace production {

  constexpr auto principle_01 = "Verification over confidence";
  constexpr auto principle_02 = "Evidence over assumptions";
  constexpr auto principle_03 = "Systems over demos";

  while (there_is_more_to_learn) {
    research();
    build();
    measure();
    break_things_safely();
    fix_root_causes();
    ship();
  }
}
```

<table>
<tr><th align="left">CONSTRAINT</th><th align="left">WHAT IT MEANS IN PRACTICE</th></tr>
<tr><td><code>OBSERVABILITY</code></td><td>If a system cannot explain its state, it cannot be trusted at scale.</td></tr>
<tr><td><code>VALIDATION</code></td><td>Confidence scores do not replace evidence, policy, or clear failure handling.</td></tr>
<tr><td><code>SIMPLE_INTERFACES</code></td><td>Complexity compounds. Keep the surface area legible and the contracts explicit.</td></tr>
<tr><td><code>ASYNC_BY_DEFAULT</code></td><td>Long-running intelligence belongs behind durable queues, not fragile request lifecycles.</td></tr>
<tr><td><code>SECURE_BOUNDARIES</code></td><td>Authentication, authorization, rate limits, and input controls are product features.</td></tr>
</table>
